# ShopeeAF Node.js

Versi Node.js/Express untuk generator link affiliate sederhana.

## Install

```bash
npm install
```

## Jalankan lokal

```bash
npm start
```

Buka:

```text
http://localhost:3000
```

## Deploy

Cocok untuk VPS/Railway/Render. Untuk Vercel, upload file lokal tidak persisten, jadi gunakan storage eksternal seperti Cloudinary/S3/Vercel Blob jika ingin gambar tetap tersimpan.
